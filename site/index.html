1.0 Chain of custody every digest, same five stages

  1. 1.1SOURCE Main branch of the public repository tektum/verity-images refs/heads/main
  2. 1.2BUILD GitHub Actions workflow, apko/melange for Wolfi, Copacetic for patched upstreams .github/workflows/build.yaml catalog run NOTEFIPS flavors on some images enable the OpenSSL 3.1.2 FIPS provider, Go FIPS mode, or both, depending on the image. Not CMVP validated.
  3. 1.3SIGN cosign keyless via GitHub OIDC identity -- issuer --
  4. 1.4ATTEST One SPDX SBOM per platform, attached to the image index digest, + SLSA build provenance SPDX-JSON signed attestation actions/attest-build-provenance GATE0 fixable at publish time, not 0 CVE. Unfixed findings stay visible on every row.
  5. 1.5PUBLISH Pushed by digest to the registry verity.supply published -- GATENo exceptions. A failed gate publishes nothing.
